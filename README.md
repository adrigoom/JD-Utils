# JD-Utils

A WIP collection of scripts for modifying or converting several file formats for UbiArt Framework-based Just Dance games.

## Supported actions

- Converting cyrilic .ktape.ckd to romanized lyrics
- Reorganizing KareokeClip json objects in a .ktape.ckd file by order of appearence (Useful for modifying/desensoring song lyrics)

## Installation

To install the required packages, run:

```bash
  pip install -r requirements.txt
```
Alteratively, you can install them by hand:
```bash
  pip install transliterate  
```
